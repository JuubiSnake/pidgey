# Pidgey
Share notes, checklists and itineraries between people and collaborate on them in real time.

## Goals

- Create a real-time collaborative platform for sharing notes, checklists and itineraries.
- Enable users to collaborate on documents in real time.
- Provide a user-friendly interface for creating, editing and sharing documents.
